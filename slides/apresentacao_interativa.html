Objetivo: comparar algoritmos supervisionados implementados do zero em um problema de classificação e um de regressão do OpenML.

O que comparamos

2. Algoritmos — kNN

k vizinhos.
Uma decisão.

fit: só guarda X e y na memória. Modelo “preguiçoso”, treino ≈ 0 s.

predict: para cada amostra, mede a distância até todo o treino, ordena e pega os k mais próximos.

Classificação: voto majoritário (k = 3).
Regressão: média dos vizinhos (k = 5).

DistânciasEuclidiana √Σ(xᵢ − yᵢ)²
Manhattan Σ|xᵢ − yᵢ|
src/knn.py 
class KNN:
    def fit(self, X_train, y_train):  # treinamento
        self.X_train = X_train
        self.y_train = y_train

    def calculate_predicts(self, x):
        distances = [self.calculate_distances(x, x_train)
                     for x_train in self.X_train]
        k_indices = np.argsort(distances)[:self.k]
        k_nearest_label = [self.y_train[i] for i in k_indices]
        if self.task == "classification":  # voto
            unique, counts = np.unique(k_nearest_label,
                                       return_counts=True)
            return unique[np.argmax(counts)]
        if self.task == "regression":      # média
            return np.mean(k_nearest_label)

    def predict(self, X_test):  # predição
        return [self.calculate_predicts(x) for x in X_test]

2. Algoritmos — Classificador Bayesiano Univariado

Uma normal por atributo, por classe.

fit: para cada classe, calcula a média μ, a variância σ² de cada atributo e a priori P(Cₖ). Assume atributos independentes.

predict: soma log da priori com o log das densidades e escolhe a classe com maior valor.

Somar logaritmos em vez de multiplicar probabilidades evita underflow numérico.

Decisãoargmaxₖ log P(Cₖ) + Σⱼ log 𝒩(xⱼ; μₖⱼ, σ²ₖⱼ)
src/classificacao/bayes.py 
class NaiveBayes:  # Univariado
    def fit(self, X_train, y_train):
        n_samples, n_features = X_train.shape
        self._classes = np.unique(y_train)
        # ... aloca _mean, _var e _prior com zeros
        for idx, c in enumerate(self._classes):
            X_c = X_train[y_train == c]
            self._mean[idx, :] = X_c.mean(axis=0)
            self._var[idx, :] = X_c.var(axis=0)
            self._prior[idx] = X_c.shape[0] / float(n_samples)

    def predict(self, X_test):
        return np.array([self._predict(x) for x in X_test])

    def _predict(self, x):
        posteriors = []
        for idx, c in enumerate(self._classes):
            prior = np.log(self._prior[idx])  # evita underflow
            posterior = np.sum(np.log(self._pdf(idx, x)))
            posteriors.append(prior + posterior)
        return self._classes[np.argmax(posteriors)]

2. Algoritmos — Perceptron Simples

Um neurônio. Uma fronteira linear.

fit: sorteia os pesos e, a cada época, percorre as amostras embaralhadas. Se a saída está errada, corrige os pesos na direção da amostra.

predict: soma ponderada das entradas (mais o bias) e função degrau: 0 ou 1.

Hiperparâmetros: taxa de aprendizado η e número de épocas. Só converge se as classes forem linearmente separáveis.

Regra de aprendizadoy = degrau(wᵀx)
w ← w + η (d − y) x
src/classificacao/perceptron.py 
class Perceptron:  # Simples
    def fit(self, X_train, y_train):
        rng = np.random.default_rng(self.random_state)
        self._classes = np.unique(y_train)
        d = (y_train == self._classes[1]).astype(int)  # 0 ou 1
        N = X_train.shape[0]
        X_train = np.column_stack((np.ones(N), X_train))  # bias
        self.w = rng.uniform(-0.5, 0.5, X_train.shape[1])
        for _ in range(self.n_epochs):
            errors = 0
            for i in rng.permutation(N):
                y = self.activation(X_train[i] @ self.w)
                e = d[i] - y
                if e != 0:  # regra de aprendizado
                    self.w += self.learning_rate * e * X_train[i]
                    errors += 1
            if errors == 0:  # convergiu
                break

    def activation(self, u):  # degrau
        return np.where(u >= 0, 1, 0)

    def predict(self, X_test):
        X_test = np.column_stack((np.ones(len(X_test)), X_test))
        return self._classes[self.activation(X_test @ self.w)]

2. Algoritmos — Regressão Linear Múltipla

Solução fechada, com estabilidade numérica.

fit: adiciona uma coluna de 1s (intercepto β₀) e resolve a equação normal uma única vez.

predict: só um produto matricial com os β já calculados. Teste em menos de 1 ms.

A pseudo-inversa de Moore–Penrose (np.linalg.pinv) funciona mesmo quando XᵀX não é invertível. Sem hiperparâmetro.

Equação normalβ = (XᵀX)⁺ Xᵀy → ŷ = Xβ
src/regressao/regressao_linear.py 
class MRegression:
    def fit(self, X_train, y_train):
        N = X_train.shape[0]
        # coluna de 1s para o intercepto
        X_train = np.column_stack((np.ones(N), X_train))
        # pseudo-inversa de Moore-Penrose
        self.beta = (np.linalg.pinv(X_train.T @ X_train)
                     @ X_train.T @ y_train)

    def predict(self, X_test):
        N = X_test.shape[0]
        X_test = np.column_stack((np.ones(N), X_test))
        return X_test @ self.beta

2. Algoritmos — Multi Layer Perceptron (MLP)

Camadas ocultas aprendem o que não é linear.

fit: a cada mini-lote, calcula a saída (forward), mede o erro e o propaga de trás para frente (backpropagation), ajustando pesos e bias pelo gradiente.

predict: só o forward. A saída é linear, pois o alvo é um número.

Hiperparâmetros: camadas ocultas, neurônios por camada, ativação (sigmoid, tanh ou ReLU), taxa de aprendizado η e épocas.

Backpropagationδₗ = (δₗ₊₁ Wₗᵀ) ⊙ f′(aₗ)
Wₗ ← Wₗ − η aₗᵀ δₗ₊₁
src/regressao/mlp.py 
class MLP:
    def fit(self, X_train, y_train):
        # ... padroniza o alvo (d) e sorteia W e b de cada camada
        for _ in range(self.n_epochs):
            indices = rng.permutation(N)
            for start in range(0, N, self.batch_size):
                batch = indices[start:start + self.batch_size]
                A = self.forward(X_train[batch])
                delta = 2 * (A[-1] - d[batch]) / len(batch)
                for l in reversed(range(len(self.W))):  # backprop
                    grad_W = A[l].T @ delta
                    grad_b = np.sum(delta, axis=0)
                    if l > 0:  # erro da camada anterior
                        delta = ((delta @ self.W[l].T)
                                 * self.derivative(A[l]))
                    self.W[l] -= self.learning_rate * grad_W
                    self.b[l] -= self.learning_rate * grad_b

    def forward(self, X):  # saída de cada camada
        A = [X]
        for l in range(len(self.W)):
            u = A[-1] @ self.W[l] + self.b[l]
            last = l == len(self.W) - 1
            A.append(u if last else self.activate(u))
        return A

    def predict(self, X_test):
        y = self.forward(X_test)[-1].ravel()
        return y * self._y_std + self._y_mean

3.2 Métricas de Avaliação

Classificação

Acurácia = (VP + VN) / N

Precisão = VP / (VP + FP)

Recall = VP / (VP + FN)

F1 = 2 · P · R / (P + R)

Precisão, recall e F1 são médias macro entre as classes.

Regressão

MAE = (1/n) Σ |yᵢ − ŷᵢ|

R² = 1 − SSres / SStot

R²aj = 1 − (1 − R²)(n − 1)/(n − p − 1)

Todas implementadas manualmente com NumPy.

Análise Crítica: Desempenho vs. Eficiência

Classificadores (acurácia e F1)

Acurácia: Bayes 0.722 ≈ kNN 0.714.

F1 macro: kNN 0.593 > Bayes 0.566. O kNN acerta mais a classe minoritária.

Teste: Bayes 0.005 s vs. kNN ~0.45 s (≈100× mais rápido).

Perceptron: acurácia 0.670 e F1 0.570. Não converge, pois as classes não são linearmente separáveis.

Regressores (R² e MAE)

kNN Manhattan: MAE 0.522 e R² 0.360.

Regressão Linear: MAE 0.570 e R² 0.288.

MLP: MAE 0.537 e R² 0.371, o maior R². Treino ~0.7 s por fold.

Teste: Linear e MLP < 1 ms vs. kNN ~24–25 s por fold; treino do kNN ≈ 0 s (só armazena).

kNN: simples e sem suposições sobre os dados, mas a previsão escala mal com o tamanho do treino. Bayes e Regressão Linear: rápidos e interpretáveis, mas assumem independência entre atributos e relação linear. MLP: aprende relações não lineares e prevê rápido, mas tem vários hiperparâmetros para ajustar.

Ajuste de Hiperparâmetros: aumentar sempre ajuda?

Não. Cada métrica tem seu melhor valor, e passar dele piora o modelo.

k do kNN · classificação

A acurácia sobe até k = 15 (0.768), mas o F1 cai de 0.604 (k = 5) para 0.442 (k = 51).

Com k grande o voto é dominado pela classe majoritária (74%): o modelo acerta mais por “chutar” class2 e esquece a class1.

Melhor k pelo F1: 5.

k do kNN · regressão

O R² sobe de 0.21 (k = 1) até 0.369 (k = 11, Manhattan) e depois cai: média de vizinhos demais suaviza a previsão.

O MAE é menor em k = 1 (0.441) porque copia notas inteiras: acerta muitas exatamente e erra feio as outras, o que o R² penaliza.

Melhor k pelo R²: 7 a 11.

Aumentar k reduz a variância e aumenta o viés. O ponto ótimo depende da métrica escolhida, por isso a métrica deve ser definida antes de ajustar.

Ajuste de Hiperparâmetros: Perceptron e MLP

No Perceptron não há tendência. No MLP, rede maior e mais épocas passam a decorar o treino.

Taxa de aprendizado e épocas · Perceptron

Nas 35 combinações o F1 fica entre 0.488 e 0.570, sem tendência: mais épocas ou outra taxa não melhoram de forma consistente.

As classes não são linearmente separáveis. O Perceptron não converge e o resultado depende de onde os pesos estavam quando o treino parou.

Usado: η = 1.0 e 200 épocas (maior F1 médio).

Topologia, ativação, taxa e épocas · MLP

Topologia: de 8 para 64 neurônios o R² sobe de 0.339 para 0.371. A melhor foi 32-16 (0.378). Com 64-32 o R² de treino vai a 0.532 e o de teste não melhora (0.370).

Ativação: ReLU 0.371 > tanh 0.365 > sigmoid 0.329. Taxa: 0.01 é a melhor; 0.1 piora (0.290) e 0.3 diverge.

Épocas: o R² de teste sobe até 100 (0.371) e cai com 400 (0.334), enquanto o de treino continua subindo (0.514).

Usado: 64 neurônios, ReLU, η = 0.01 e 100 épocas.

No MLP, a distância entre o R² de treino e o de teste mede a generalização: quando ela cresce, o modelo está sobreajustando.

Z-score: Por Que e Onde Aplicamos

z = (x − μ) / σ · cada atributo passa a ter média 0 e desvio-padrão 1

Por que usamos

No Wine Quality os atributos têm escalas muito diferentes: o SO₂ total vai de 6 a 440 e a densidade de 0.987 a 1.039.

O kNN mede distâncias: sem padronizar, o atributo de maior escala decide sozinho quem é vizinho.

Perceptron e MLP somam entradas ponderadas: escalas diferentes desequilibram o ajuste dos pesos e saturam as ativações.

Em que etapa

Dentro de cada fold, logo depois da divisão em treino e teste.

μ e σ são calculados só no treino. O teste é transformado com esses mesmos valores, sem vazamento de dados.

Aplicado aos atributos de todos os algoritmos, nas duas bases. O alvo não passa por esse pré-processamento.

Todos os algoritmos recebem os dados no mesmo formato, o que mantém a comparação justa.

Z-score: Discussão e Conclusão Crítica

Discussão dos resultados

Neutro para Bayes e Regressão Linear: média e variância por atributo e os coeficientes β se ajustam à escala, e a previsão não muda.

Decisivo na regressão: sem Z-score o R² do kNN cai de 0.36 para 0.16–0.18 e o do MLP de 0.371 para 0.00, o mesmo que prever sempre a média.

Pequeno na classificação: os atributos já são 0 ou 1. O kNN ganha 0.016 de F1. O Perceptron sem Z-score tem acurácia maior (0.712), mas por prever mais a classe majoritária: o F1 cai de 0.570 para 0.490.

Conclusão crítica

O uso foi adequado: pelo F1 e pelo R², o Z-score melhorou ou manteve o resultado de todos os algoritmos, e sem ele kNN e MLP não funcionam no Wine Quality.

Ajustes possíveis: dispensar a padronização no Bayes e na Regressão Linear, onde ela não tem efeito, e avaliar o AutoUniv sem ela, já que os atributos são binários.

Alternativas: Min-Max, ou uma escala robusta (mediana e intervalo interquartil) para os atributos do vinho com valores extremos, como o açúcar residual (até 65.8).

Z-score: indispensável para kNN e MLP quando os atributos têm escalas diferentes, e neutro para Bayes e Regressão Linear.

4. Conclusões

Melhor equilíbrio: Bayes Univariado e MLP.

Melhor desempenho: kNN no F1 da classificação (0.593; 0.604 com k = 5) e MLP na regressão (R² 0.371 e RMSE 0.692). O menor MAE é do kNN Manhattan (0.522).

Mais rápidos no teste: Bayes Univariado (0.005 s), Regressão Linear e MLP (< 1 ms).

Vale a pena? Na classificação, o Bayes entrega acurácia equivalente ~100× mais rápido. Na regressão, o MLP iguala o kNN prevendo em menos de 1 ms, contra ~25 s por fold, ao custo de ~0.7 s de treino.

Z-score: indispensável para kNN e MLP no Wine Quality e neutro para Bayes e Regressão Linear.

Limitações: dataset de classificação artificial, ruidoso e desbalanceado (prever sempre a classe majoritária daria 0.741 de acurácia), no qual o Perceptron não converge; R² moderado no Wine Quality; hiperparâmetros escolhidos sem validação aninhada.
